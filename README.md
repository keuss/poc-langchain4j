## Run the demo

 - mvn clean package

```bash
# Sur Windows (CMD) :
set OPENAI_API_KEY=xxx...
java -jar target/langchain4j-open-ai-demo-1.0-SNAPSHOT-jar-with-dependencies.jar

# Sur Linux / Mac / Windows (PowerShell) :
export OPENAI_API_KEY="xxx..."
java -jar target/langchain4j-open-ai-demo-1.0-SNAPSHOT-jar-with-dependencies.jar
```
